# Frontend (React + TypeScript + Vite)

Scaffolded when the review UI is built (Stage 1, Step 5). Feature folders:

- `src/features/import`  — upload + coverage check
- `src/features/scenes`  — scene list / scene detail with source text
- `src/features/review`  — the review queue (heart of the tool)
- `src/features/reports` — scene / character / location / combination / day-night reports
- `src/features/query`   — composable structured filters; every number drills down to scenes
